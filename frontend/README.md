## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/smart-expense-tracker.git
cd smart-expense-tracker
```

### 2. Install backend dependencies

```bash
cd backend
npm install
```

### 3. Install frontend dependencies

```bash
cd ../frontend
npm install
```

### 4. Configure environment variables

Create a `.env` file inside the `backend` folder:

```env
PORT=5001
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
```

Create a `.env` file inside the `frontend` folder if required by your current API configuration.

### 5. Run the backend

```bash
cd backend
npm run dev
```

### 6. Run the frontend

Open another terminal:

```bash
cd frontend
npm run dev
```

Then open the local URL shown by Vite.

## 🔒 Security

* Passwords are hashed using bcrypt.
* JWT authentication protects private routes.
* Environment variables are used for sensitive credentials.
* User financial data is isolated by authenticated user.
